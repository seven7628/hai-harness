# 产品命名规范（2026-11）

> 适用范围：桌面端 Hub、设置弹窗、左栏、输入区、右栏、审批/提问、消息与产出、用量、技能与定时任务页面，以及英文同层级文案。
> 本文是**可执行的规范**，不是文案赏析：每条规则都对应到 `desktop/app/src/i18n.ts` 的用户可见值，或明确列进「未落地清单」。
> 硬边界：**i18n key、代码标识符、配置字段名不改，只改用户可见的值。** 例外只有一处：为 5 组 13 项的设置 IA 新增了两个分组标题 key（见 §3.3），没有删除任何 key。

---

## 0. 一页纸总纲

### 四条硬规则

1. **一个对象只有一个名字，UI 不出现代号。**
   工作区、会话、任务、技能、插件、面板、外部工具、自动化、模型服务、消息接入、会话协作、项目记忆、记忆巡检、用量——同一概念全站只用一个词。代码名（Dream / Surface / Session Mesh / MCP / Cron / Span / Trace / V3 / v2）不进用户界面；技术标识（`mcp__<server>__<tool>`、`SKILL.md`、`session_send`、URL、路径、用户必须原样输入的内容）除外。

2. **导航与按钮 2–4 字，说明尽量 ≤24 字。**
   一句说清「是什么 / 点了会怎样」。超了就拆句，或砍掉不影响决策的半句。设置左栏 13 项全部 2–4 字。

3. **专业但不端着：用日常词，不用口语缩写。**
   禁止「改 / 删 / 跑 / 停 / 成了 / 没成 / 先停停 / 拿掉 / 打不开 / 放不了」这类缩写或撒娇式说法。按钮用完整动词：编辑、删除、运行、停止、打开、无法播放。

4. **中英同层级、同信息；技术词只在必须处出现。**
   英文用产品名（Model services / External tools / Automation / Plugins / Surfaces / Chat apps / Session mesh / Mobile / Project memory / Usage），正文里的 `agent`、`provider` 保持小写普通名词。中文导航不出现 `Provider`、`MCP`、`Agent`、`Skill`、`Cron`、`Dream`。

### 三条软规则

- 能猜到的就别写：`保存` 比 `保存并生效` 好，`刷新` 比 `刷新连接状态` 好。
- 状态与错误必须给出路：`播放器无法打开这个文件——可以试试系统播放器`，不要只写「失败」。
- 同一概念不混用：`工作区` 不写 `项目`（「项目记忆」是固定产品名），`会话` 不写 `对话`，`自动化` 不写 `钩子`，`面板` 不写 `面板插件`，`用量` 不写 `使用统计`。

## 2. 对象层级

```
工作区 Workspace
└─ 会话 Session                 ← 侧栏一条持久线程
   ├─ 回合 Turn                 ← 一次输入到模型结束
   │  ├─ 运行 Run               ← 一次执行，有状态
   │  ├─ 工具调用 / 外部工具
   │  ├─ 技能 Skill
   │  └─ 自动化 Automation
   └─ 任务 Task                 ← 定时任务 / 后台任务，也可独立存在
      └─ 运行 Run               ← 执行记录 / 执行详情
```

- 「运行」是**任务/巡检/脚本的执行实例**，不是对象分类；不要在导航里写「运行」。
- 「任务」只用于定时任务与后台任务；不要用它指会话或一次模型回答。
- 面板与插件是**扩展 UI/运行时**，不是数据对象；不进入「工作区 > 会话」层级。
- 连接类（消息接入、会话协作、手机连接）是**跨端入口**，设置里单独成组。

## 3. 设置 IA（5 组 13 项）

### 3.1 分组与条目

| 组 | 项 | i18n key | 中文 | English | 旧值 |
|---|---|---|---|---|---|
| 基础 | 通用 | `settings.general` | 通用 | General | 通用设置 |
| 基础 | 外观 | `settings.appearance` | 外观 | Appearance | 外观 |
| 基础 | 快捷键 | `settings.shortcuts` | 快捷键 | Shortcuts | 快捷键 |
| 模型 | 模型服务 | `settings.provider` | 模型服务 | Model services | Provider |
| 能力 | 外部工具 | `settings.mcp` | 外部工具 | External tools | MCP |
| 能力 | 自动化 | `settings.hooks` | 自动化 | Automation | 钩子 |
| 能力 | 插件 | `settings.plugin` | 插件 | Plugins | 插件 |
| 能力 | 面板 | `settings.surfaces` | 面板 | Surfaces | 面板插件 |
| 连接 | 消息接入 | `settings.im` | 消息接入 | Chat apps | IM 集成 |
| 连接 | 会话协作 | `settings.mesh` | 会话协作 | Session mesh | 会话通信 |
| 连接 | 手机连接 | `settings.mobile` | 手机连接 | Mobile | 手机连接 |
| 数据 | 项目记忆 | `settings.memory` | 项目记忆 | Project memory | 项目记忆 |
| 数据 | 用量 | `settings.usage` | 用量 | Usage | 使用统计 |

- **默认打开「通用」**；关闭设置后再次打开仍回到「通用」（现有逻辑，未改）。
- 分组标题 2 字、弱色、小字；条目 2–4 字。
- 分组标题：基础 / 模型 / 能力 / 连接 / 数据（en: Basic / Model / Capabilities / Connections / Data）。
- 分组是**能力边界**，不是技术栈边界：外部工具、自动化、插件、面板都在「能力」；消息接入、会话协作、手机连接都在「连接」。

### 3.2 为什么不把「项目记忆 / 用量」放进「能力」

它们是**数据**：项目记忆是跨会话沉淀，用量是历史统计；放进能力组会让「能力」变成杂物抽屉。数据组只有两项，符合 5 组 13 项的稳定结构。

### 3.3 key 变更说明

- 新增 `settings.nav.base`（基础 / Basic）与 `settings.nav.conn`（连接 / Connections）：5 组必须有 5 个标题，这是唯一无法只改值的地方。
- `settings.nav.agent` **保留 key**，值从「Agent 能力」改为「能力」：能力组沿用旧 key，避免删 key 造成引用风险。
- 其余 13 个条目、标题均为**只改值**。没有删除 key，没有改 key 名，没有改代码标识符。

## 6. 时间格式

- 用户可见时间统一 **`YYYY-MM-DD HH:mm`**，24 小时制；秒只在调试视图出现。
- 相对时间只在更清楚时使用：`刚刚`、`几分钟前`；超过 1 小时用绝对时间。
- 时间范围用 en dash：`2026-11-01 09:00 – 2026-11-30 18:00`。
- 定时任务、执行记录、记忆巡检的运行记录都遵循此格式。

**未落地**：`SettingsModal.tsx` 的 `fmtDreamRunTime()` 仍用 `toLocaleString()`，会受系统区域设置影响（可能输出 `11/15/2026, 9:30:00 PM`）。DreamSection 逻辑按边界不在此任务改，已列入 §11，需改成上述格式。

## 7. 错误文案模式

**结构**：`[哪一步] + [为什么] + [下一步]`。状态 chip 可以只写「失败」，正文必须给出路。

| 不要写 | 改成 | 理由 |
|---|---|---|
| 图片没能显示 | 图片无法显示 | 「没能」是口语缩写 |
| 这个文件放不了 | 这个文件无法播放 | 补全动词，说明是播放问题 |
| 播放器打不开这个文件… | 播放器无法打开这个文件（编码或容器不被支持）——可以试试系统播放器 | 给原因 + 下一步 |
| 添加文件失败，请重试 | 添加文件失败，请重试 | 已有下一步，保留 |
| 保存失败 | 保存失败，请重试 | 单句错误也要给动作 |
| 读取失败 | 读取失败，请刷新重试 | 状态 + 动作 |

规则：

- 说明尽量 ≤24 字；错误正文可以略长，但只讲一件事。
- 用「无法 / 失败 / 不可用」，不用「打不开 / 放不了 / 转不了 / 没能」。
- 不给堆栈、内部错误码、代码名；技术标识（路径、URL、模型名）必须原样保留。
- 英文同一层级：`Could not … — <next step>`；不要只写 `Error`。

## 8. 中英规则

- 英文导航/标题用产品名：**Workspace / Session / Task / Skills / Plugins / Surfaces / External tools / Automation / Model services / Chat apps / Session mesh / Mobile / Project memory / Memory sweep / Usage**。
- 英文正文里的 `agent`、`provider`、`session` 保持小写普通名词；不要把它们当导航名。
- 中文导航不出现英文产品名（Token、URL、模型名、路径除外）。
- 同一 key 的中英必须同层级、同信息；英文可以更短，但不能换概念。
- 英文动作统一：Send / Stop / Queue / Retry / Open / Rename / Delete / Cancel / Review / Approve / Deny / Always allow / Files / Changes / Tasks / Process / Preview / Copy / Reveal in folder。
- `Skills` 在英文里是自然复数；中文一律「技能」。
- `MCP` 只允许在 `mcp.hint` 的协议说明里出现一次；英文同样只此一处。

## 12. 禁止词扫描（可复跑）

在 worktree 根目录执行（脚本会进入 `desktop/app`）。脚本只读 `src/i18n.ts`，不改文件；有阻塞项时退出码 1。

```bash
cd desktop/app
python3 - <<'PY'
import re, sys
src = open('src/i18n.ts', encoding='utf-8').read()
zs, es = src.index('const zh:'), src.index('const en:')
line = re.compile(r"^  '([^']+)': (['\"])(.*)\2,\s*(?://.*)?$", re.M)
def table(s): return {k: v for k, _, v in line.findall(s)}
zh, en = table(src[zs:es]), table(src[es:])
zh_bad = re.compile(r'钩子|Provider|面板插件|使用统计|IM 集成|会话通信|Dream|Span|Trace|Skills|(?<![A-Za-z])Agent(?![A-Za-z])')
en_bad = re.compile(r'\b(Trace|Span|Dream)\b|Panel plugins|IM Integration|Session communication')
allow = {'mcp.hint'}                     # MCP 协议名只允许在这一条出现一次
pending = lambda k: k.startswith(('cron.', 'skill.', 'settings.narrativeSkin.'))
blocking, known = [], []
for k, v in zh.items():
    bad = zh_bad.search(v)
    if 'MCP' in v and k not in allow: bad = bad or 'MCP'
    if bad:
        hit = bad.group(0) if hasattr(bad, 'group') else bad
        (known if pending(k) else blocking).append((k, hit, v))
for k, v in en.items():
    bad = en_bad.search(v)
    if bad: (known if pending(k) else blocking).append((k, bad.group(0), v))
print(f'BLOCKING: {len(blocking)}')
for k, hit, v in blocking: print(f'  {k}: [{hit}] {v[:100]}')
print(f'KNOWN PENDING (Cron/Skills/narrativeSkin): {len(known)}')
for k, hit, v in known: print(f'  {k}: [{hit}] {v[:100]}')
print('keys zh/en:', len(zh), len(en),
      'only-zh:', sorted(set(zh)-set(en)), 'only-en:', sorted(set(en)-set(zh)))
sys.exit(1 if blocking or set(zh) != set(en) else 0)
PY
```

- 中文值禁止：`钩子 / Provider / 面板插件 / 使用统计 / IM 集成 / 会话通信 / Dream / Span / Trace / Skills / Agent`；`MCP` 只允许 `mcp.hint`。

- 同时校验 zh/en key 集合完全一致（本轮 2156 / 2156）。

## 14. 决策记录（默认选择与理由）

1. **保留「会话」而不改「对话」**：见 §9。会话是持久对象；「对话」只用于聊天场景的描述，不作对象名。
2. **「自动化」而不是旧稿「自动动作」**：功能名和条目名分层（自动化 / 规则），避免与定时任务混淆。
3. **「面板」而不是「面板插件」**：插件与面板是两套系统；面板不是插件。
4. **「智能体」而不是「AI 助手」**：4 字、行业通用、已有使用；子/主用「子智能体 / 主智能体」。
5. **「记忆巡检」而不是 Dream**：Dream 是内部代号；用户只需要知道「定时检查记忆」。
6. **新增 `settings.nav.base` / `settings.nav.conn`**：5 组 IA 的必要标题；保留 `settings.nav.agent` key 只改值，尽量少动 key。
7. **「已完成」与「成功」并存**：任务生命周期用「已完成」，运行/工具结果用「成功」；避免把任务完成误读为结果成功。
8. **Cron/Skills 只改 3 个值（`cron.settingsGeneral`、`skill.pageTitle`、`plugin.browser.usage`）**：按后续指示修正残留；其余 `cron.*` / `skill.*` 仍归并行任务，避免与组件改造冲突。
9. **不修导航溢出**：边界明确不改 CSS；已给出可执行的 CSS 修复建议和实测数据。
10. **英文保留 agent/provider 小写正文**：导航与标题用产品名；正文用自然英文，不硬译「智能体/模型服务」。
