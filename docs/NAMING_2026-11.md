## 一页纸总纲（草稿）

1. 一个对象只有一个名字；UI 不出现代码名。
2. 导航与按钮 2–4 字，说明尽量 ≤24 字，一句说清「是什么 / 点了会怎样」。
3. 专业但不端着：不用「改 / 删 / 跑 / 停 / 成了 / 没成」这类口语缩写。
4. 中文优先用日常词；英文同层级用产品名（Model / External tools / Automation / Plugins / Surfaces / Chat apps / Session mesh / Mobile / Usage）。
